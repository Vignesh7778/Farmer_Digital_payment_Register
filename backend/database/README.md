# Backend Schema & Database configuration

This directory contains the database setup for the Farmer Produce Collection application.

- `schema.sql`: Table structure (Farmers, Produce, Collections, Payment_History)
- `functions.sql`: Server side triggers and constraints validation logic
- `policies.sql`: Row-Level Security policies
- `views.sql`: Custom database views for dashboard calculations
- `seed.sql`: Initial seed data for local setup and testing
